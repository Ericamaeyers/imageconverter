# Image to WebP Converter — Dark UI Edition

Local browser-based PNG/JPG/JPEG to WebP converter.

## Included
- Dark purple interface based on the approved mockup
- Custom logo and animated coffee mug in drag/drop area
- Drag and drop + Add More
- Multiple image conversion
- Optimized mode with adjustable 70–100% quality
- Preserve Quality mode using maximum browser WebP quality
- Per-file original size, converted size, savings and status
- Per-file preview/download/remove controls
- Download selected or download all
- Everything runs locally in the browser

Open `index.html` in Chrome, Edge, Safari, or Firefox.

Note: the browser Canvas API does not expose a guaranteed lossless WebP switch in every browser. Preserve Quality uses maximum WebP quality available through the browser encoder.
